## 3. 完成标准自查（交前逐条打勾）

- [ ] ROI 约束：只保留框中心落在 ROI 内的候选
- [ ] 单目标锁定：有历史选最近的（超距离视为失败）；无历史选面积最大的
- [ ] 丢帧外推：连续丢失超过 `max_miss`（默认 2）返回空
- [ ] EMA 一阶低通
- [ ] 组帧：`@TAG,v1,v2,v3*CS#`，校验和 = 载荷 ASCII 和 %100（两位）
- [ ] UDP 发送能通（本机回环即可，不需要单片机）
- [ ] 组帧后再解析回来：标签 / 字段数 / 校验和都对得上
- [ ] 遮住目标 2 帧：前两帧是外推位置，第 3 帧是 `q=0`（不是发 0）
