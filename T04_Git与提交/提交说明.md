## 3. 完成标准自查（交前逐条打勾）

- [ ] 工作目录 `git init` 过（是 git 仓库）
- [ ] 配置了远程仓库 `origin`
- [ ] 提交数 ≥ 3（不是一次全塞进去，是分次提交）
- [ ] 仓库里有 `README.md`（别人点进去能看懂这是啥）
- [ ] 仓库里有 `.gitignore`（别把权重和大视频传上去）
- [ ] 工作区干净：`git status` 没有一堆未提交的改动
