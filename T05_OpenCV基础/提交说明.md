## 3. 完成标准自查（交前逐条打勾）

- [ ] `load_image`：读图（中文路径必须用 `vision_util.imread`）
- [ ] `to_gray`：BGR → 灰度
- [ ] `crop_roi`：切 ROI，记住是 `img[y1:y2, x1:x2]`（先高后宽）
- [ ] `resize_keep`：等比缩放（保持长宽比）
- [ ] `draw_marker`：画框 + 十字 + 文字
- [ ] `read_frames`：读视频 / 摄像头帧序列
- [ ] 没有把 `cv2.imread` 用在中文路径上（会返回 `None`）
- [ ] 没有把 ROI 切片写成 `[x1:x2, y1:y2]`
