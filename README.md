# 提交模板（每任务一份现成文件夹）

> **这一份就是「照抄格式」用的**：每个任务都有现成文件夹，复制、改名、填空、打包，交上去。

## 一、三种模板，按需选

| 位置 | 用途 |
|---|---|
| `T01_环境验收/` … `T09_训练自己的YOLO/` | **必修任务**（T01–T09），每个任务一份现成文件夹 |
| `E1_…/` … `E4_…/` | **选做任务**（E1–E4，学有余力再做） |
| `示例提交_T06_2025xxxx_张三/` | **完整示范**：一份填好的 T06 提交，照着它的样子写就行 |
| `作业提交模板.md` | 通用空白模板（想手写、或现有文件夹都不合适时用） |

> ⚠️ **任务号和目录号差一位，认文件夹名就行**：第六章 `06_传统视觉/` 里有两个任务（T06、T07），
> 所以 **T08 在 `07_YOLO推理/`、T09 在 `08_训练自己的YOLO/`** —— T09 是「训练自己的 YOLO」，
> **不是** `09_拓展/`（那里是选做的 E1–E4）。认不准就看每个文件夹里「提交说明.md」的**对应目录**那一行。

每个任务文件夹里都是同一套结构：

```
T06_传统视觉/
├─ 提交说明.md            ← 主要交这个：填信息、贴图、逐条打勾
├─ 截图/                  ← 放你的关键截图（整段截，别只截最后一行）
└─ 代码/                  ← 放你写的代码（或在文档里填仓库地址 + commit hash）
```

## 二、三步交作业

1. **自检**：对照该任务「完成标准」页（`提交说明.md` 第 3 节已抄好）逐条核对。
2. **复制改名**：整个文件夹复制一份 → 重命名成 `T06_2025xxxx_张三/` →
   把 `提交说明.md` 也改名成 `T06_2025xxxx_张三.md`（双保险，助教一眼知道是谁的）。
3. **交上去**：打包交到群里发布的「作业收集表」；如果已经在用 Git，就 `git push` 后把仓库地址 + commit hash 填进文档。

## 三、命名规范

```
提交文件夹：  T06_2025xxxx_张三/
提交文档：    T06_2025xxxx_张三.md
关键截图：    T06_终端.png      T06_结果图.png
录屏：        T07_追踪.mp4
大文件：      T09_dataset.zip   T09_best.pt        ← 走网盘，把链接写进文档
```

## 四、大文件怎么办

`best.pt`、`dataset/`、视频这类，**不要塞进提交包**：传网盘，在 `提交说明.md` 的「代码位置」一行写上链接 + 提取方式。
（Git 仓库同理，`.gitignore` 里应该已经把 `*.pt`、`dataset/`、`runs/` 排除掉了。）

## 五、交前 30 秒自查

- [ ] 文件夹名 / 文档名带上了**任务号 + 学号 + 姓名**
- [ ] 截图为**整段**（含你敲的命令），且**是自己的**结果
- [ ] 「完成标准自查」逐条打了勾，能在文档里对上数字（帧率 / 坐标 / mAP / cm_per_pixel）
- [ ] 代码放了，或仓库地址 + commit hash 填了
- [ ] 大文件给了网盘链接，没有硬塞进包

## 六、两个提醒（心里有数）

1. 自检没全过就先别交，修好再交（不限次数）；
2. 结果图请用自己跑出来的——交作业是为了确认你真的会了。
